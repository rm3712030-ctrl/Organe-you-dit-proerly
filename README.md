# منظّم الأكل أثناء الدوام

تطبيق ويب بسيط باللغة العربية يساعد الموظفين على تنظيم أوقات وجباتهم ووجباتهم الخفيفة بما يتناسب مع جدول دوامهم اليومي واجتماعاتهم.

## نظرة عامة

يقوم المستخدم بإدخال:
- وقت بداية الدوام ونهايته
- مدة الاستراحة المتاحة (بالدقائق)
- تفاصيل إضافية (الاجتماعات، وقت الاستيقاظ، الوجبات المفضلة، الحاجة لوجبات خفيفة... إلخ)

بعد ذلك يرسل التطبيق هذه المعلومات إلى واجهة خلفية (`/api/chat`) للحصول على اقتراح جدول أكل عملي مبني على مساعد ذكاء اصطناعي، مع الاحتفاظ بسجل المحادثة لتحسين الاقتراحات اللاحقة.

## المزايا

- **واجهة عربية (RTL)** مصممة بالكامل لدعم الاتجاه من اليمين لليسار.
- **عبارات تحفيزية عشوائية** تظهر وتتغيّر بعد كل اقتراح لتشجيع المستخدم على الاستمرار.
- **نموذج إدخال بسيط** لأوقات الدوام والاستراحة والتفاصيل الحرة.
- **معالجة حالات التحميل والأخطاء** أثناء انتظار الرد من الخادم.
- **سجل محادثة (history)** يُرسل مع كل طلب للحفاظ على سياق المحادثة.

## هيكل الملف

ملف واحد (`index.html`) يحتوي على:
- `HTML` لبنية الصفحة (نموذج الإدخال وقسم عرض النتيجة)
- `CSS` مضمّن لتنسيق الشكل العام (بطاقات، ألوان، تخطيط شبكي متجاوب)
- `JavaScript` مضمّن يدير:
  - جمع بيانات النموذج
  - إرسال طلب `POST` إلى `/api/chat`
  - عرض النتيجة أو رسالة الخطأ
  - تدوير العبارات التحفيزية

## المتطلبات

يحتاج هذا التطبيق إلى نقطة نهاية خلفية (backend endpoint) على المسار:

```
POST /api/chat
```

يجب أن تستقبل هذه النقطة جسم طلب بالشكل التالي:

```json
{
  "message": "نص يصف دوام المستخدم وتفاصيله",
  "history": [
    { "role": "user", "content": "..." },
    { "role": "assistant", "content": "..." }
  ]
}
```

وتُعيد استجابة بالشكل:

```json
{
  "reply": "نص الجدول أو الاقتراح المقترح"
}
```

## طريقة الاستخدام

1. افتح ملف `index.html` في المتصفح (أو استضفه مع الخادم الذي يوفّر `/api/chat`).
2. حدد وقت بداية ونهاية الدوام ومدة الاستراحة.
3. أضف أي تفاصيل إضافية في الحقل النصي (اجتماعات، تفضيلات، إلخ).
4. اضغط على زر **"أنشئ جدول الأكل"** لعرض الاقتراح.

## ملاحظات تقنية

- لا توجد اعتماديات خارجية (لا مكتبات جافاسكريبت أو أطر عمل)، الملف يعمل مباشرة في المتصفح.
- التصميم متجاوب باستخدام `grid` مع `auto-fit` لدعم الشاشات المختلفة.
- الأزرار تُعطَّل أثناء انتظار الاستجابة لمنع الإرسال المتكرر.
